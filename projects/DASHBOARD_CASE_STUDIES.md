## Stock Market Performance Dashboard

### Summary
Interactive Tableau dashboard built to analyze historical stock market performance, compare trends, and communicate financial patterns through visual storytelling.

### Focus Areas
- Time-series analysis
- Historical trend comparison
- Financial performance visualization
- Interactive dashboard design

### Tools
- Tableau Public
- Stock market data
- Visual analytics
- Dashboard design

### Recruiter-Facing Description
Designed an interactive Tableau dashboard to analyze stock history, compare market performance, and visualize trends over time. The dashboard demonstrates financial data storytelling, time-series visualization, and business intelligence design principles.
