# Case Study Template

Use this structure for future portfolio projects.

## Project Title

Example:

```text
Generative AI Marketing Optimization Platform
```

## Executive Summary

Write 3–5 sentences explaining the business problem, your approach, and the value of the project.

## Business Problem

What challenge did this solve?

Example:

```text
Automotive dealerships often need to generate targeted marketing campaigns quickly from changing vehicle inventory. The challenge was to design an AI workflow that could turn semi-structured inventory data into audience-specific campaign recommendations and usable marketing content.
```

## Role

Example:

```text
Data Scientist / AI Workflow Designer
```

## Tools and Technologies

- Python
- SQL
- LLM workflows
- Prompt engineering
- Rule-based logic
- Scoring models
- Data visualization

## Data

Describe the data in safe, non-sensitive terms.

Example:

```text
The project used semi-structured vehicle inventory data, including pricing, model features, vehicle attributes, affordability indicators, and audience-fit signals.
```

## Methodology

1. Defined the campaign-generation problem
2. Identified input data and useful vehicle attributes
3. Designed LLM prompts for content generation
4. Built rule-based logic for timing and audience targeting
5. Created scoring model for lead potential and urgency
6. Designed end-to-end workflow from inventory selection to campaign output

## Key Features

- Campaign generation
- Audience targeting
- Urgency scoring
- Lifestyle messaging
- Affordability positioning
- Inventory prioritization

## Results

Explain what the project produced.

Example:

```text
The final workflow generated structured campaign recommendations, audience-specific messaging and vehicle prioritization scores to support faster, more consistent dealership marketing decisions.
```

## Business Value

- Reduces manual campaign planning time
- Improves consistency of marketing strategy
- Connects inventory data to audience targeting
- Supports faster decision-making
- Demonstrates practical generative AI application

## Future Improvements

- Add live dealership inventory feed
- Add dashboard view for campaign rankings
- Add A/B testing performance feedback
- Connect model output to CRM or marketing automation tools
